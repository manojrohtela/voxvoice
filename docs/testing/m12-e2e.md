## 2. Defects found and fixed

| # | Found by | Defect | Fix |
|---|---|---|---|
| 1 | `sdk.mjs` in Chrome | **The SDK could not run in a browser at all.** It called the global `fetch` unbound; a browser throws `Illegal invocation`, which the SDK reported as "Could not reach the VoxVoice API". | Bind it in `client.ts` and `signalling.ts`. Regression test reproduces the browser rule (it fails without the fix). |
| 2 | browser, Settings | A long email ran into the next column: table cells had no horizontal padding. | Space adjacent cells; the member cell opts into breaking long values (`.cell--break`). Breaking *every* cell also split short words ("owne r"), so it is opt-in. |
| 3 | browser, 1024/768 px | The Developer docs page overflowed horizontally: a wide code block set the page grid's minimum width. | `.page { grid-template-columns: minmax(0, 1fr) }`. Wide content now scrolls inside its own box. |
| 4 | browser, every page | `/favicon.ico` 404 on every page load. | An empty `<link rel="icon">`. |
| 5 | `sdk.mjs` | **Documentation defect:** the developer API docs said `POST /v1/sessions` starts a session no caller can join. On a **voice-enabled** server it fails with `502`. | Corrected in `developer-api.md` §5, the SDK README and the console docs page. |

Nothing else was changed: no feature, no API, no runtime, no telemetry, no schema.

## 3. Visual validation

**Achieved for the first time** (M12.2–M12.9 could not: `chrome --screenshot` cannot sign in and
hung after one capture). `e2e/browser.mjs` drives one long-lived page over the DevTools protocol,
so it signs in through the UI and holds a real session cookie.

Captured and reviewed: sign-in, empty Overview, agent editor, agents list, Playground idle and
**connected**, conversation detail, conversations list, Analytics, Overview, the one-time API key,
Developer docs, Settings, after an organization switch, and the Overview at 1024 / 768 / 390 px.
Per page it also checked that every button and link has an accessible name, every field has a
label, and nothing overflows horizontally — at all three widths.

Not covered: colour contrast, screen-reader output, and browsers other than Chrome.

## 4. Performance baseline

Local SQLite, one organization of **200 conversations / 1,200 events / 5 agents**, warm, best–worst
of five:

| Endpoint | |
|---|---|
| `GET /v1/console/overview?range=30d` | 16–17 ms |
| `GET /v1/console/analytics/{summary,latency,timeseries,agents}?range=30d` | 12–15 ms each |
| `GET /v1/console/conversations?limit=25` | 5–6 ms |
| `GET /v1/console/agents` · `/me` · `/meta` | 3–4 · 3–4 · 1 ms |

The Overview's single request replaces the four analytics calls it composes (~16 ms against ~62 ms).
Page loads fetch session and metadata once each, with no per-item requests (the browser run recorded
43 page loads and no fan-out). These are local numbers on one machine; they say nothing about
production capacity.

## 5. Known limitations, classified

| Limitation | Classification |
|---|---|
| **F-1** barge-in unresolved; `allow_interruptions` has no effect | **DEFER** — owner decision, runtime change. Verified unchanged here. |
| **F-7** latency semantics (endpointing off → no voice-to-voice) | **Not a defect.** Verified end to end: missing stays "not measured", never 0. |
| **F-4** developer API default `language="en-IN"` is unsupported by the recognizer | **DEFER** — changing a frozen API default. Documented in the contract, README and console docs. |
| **F-5** developer API `DELETE /v1/agents/{id}` hard-deletes | **DEFER** — frozen contract; the console archives instead. |
| `PATCH /v1/agents/{id}` with `null` on a non-nullable field → **500** | **DEFER** — the fix belongs in the frozen `api/routers/agents.py`. The SDK's type does not offer it; the contract documents it. |
| Developer API has no rate limiting | **DEFER** — no seam exists; a real one is a security-hardening milestone. |
| No durable API-key audit trail (`dp_api_key_meta` not built) | **DEFER** — creation and revocation are logged. Revisit if certification requires history. |
| SDK unpublished (install from the repository) | **DEFER** — release decision. |
| Timestamps carry no UTC offset | **DEFER** — frozen response contract; documented everywhere it is returned. |
| M12.6 turn query cost grows with the whole event log | **DEFER** — measured fine at this scale; the bounding indexes are on frozen schemas. |
| Postgres not exercised | **DEFER** — no driver installed; SQLite results say nothing about Postgres. |
| Conversation detail renders every turn (a harness call produced 149) | **DEFER** — UX debt: no pagination for very long conversations. |
| Real spoken call with real providers | **Not executed** — no provider credentials here; a person is needed. `local-run.md` §7a. |

## 6. What the harness deliberately does not prove

The speech providers are deterministic test ones. Nothing here is evidence about real speech,
audio quality or real-call latency. The harness reports `transport=webrtc` because the **media
path** is real WebRTC; the console's "real providers" label is a harness artefact of that.
